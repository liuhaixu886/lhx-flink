# 工单-说明

## 一、工单名称

实时数仓项目开发与 ADS 实时可视化看板建设。

## 二、工单背景

当前业务系统存在 MySQL 业务数据和日志数据两类实时数据源。为了支撑实时交易分析、流量监控、商品排行、省份交易排行等实时指标，需要建设一套从数据采集、清洗、分层、汇总到可视化展示的实时数仓链路。

本项目基于 Flink、Kafka、Flink CDC、HBase、Doris 和 Vue 可视化技术完成实时数仓建设。数据从 MySQL 和 Kafka 进入 ODS 层，经过 DIM、DWD、DWS、ADS 分层处理，最终由实时看板读取 Doris ADS 视图进行展示。

## 三、建设目标

- 实现 MySQL `gmall` 业务库实时变更采集。
- 实现日志数据实时接入、格式校验和分流。
- 建设 ODS、DIM、DWD、DWS、ADS 分层链路。
- 将维度数据配置化写入 HBase。
- 将交易、流量等汇总指标写入 Doris。
- 建设 ADS 实时可视化看板，实现 5 秒自动刷新。
- 支持交易 GMV、SKU TopN、省份 TopN、PV、UV、SV、趋势图等指标展示。

## 四、技术架构

```text
MySQL gmall
  -> Flink CDC
  -> Kafka topic_db
  -> ODS ods_db
  -> DWD 业务明细
  -> DWD 订单明细事实宽流
  -> DWS 30秒窗口汇总
  -> Doris ADS
  -> 实时看板

Kafka topic_log
  -> ODS ods_log
  -> DWD 日志分流
  -> DWS 流量30秒窗口汇总
  -> Doris ADS
  -> 实时看板

MySQL 配置表
  -> Flink CDC 广播流
  -> DIM 维度分流
  -> HBase gmall_dim
```

## 五、核心技术选型

| 技术 | 用途 |
| --- | --- |
| Flink 1.13.1 | 实时流处理、窗口计算、状态管理 |
| Flink CDC 2.1.1 | 采集 MySQL Binlog，实现业务数据实时同步 |
| Kafka | 实时数据缓冲、ODS/DWD 主题承载 |
| Fastjson | JSON 解析、格式校验、字段处理 |
| HBase | 存储 DIM 维度数据，支持后续维度关联 |
| Doris | 存储 DWS/ADS 汇总结果，支撑低延迟查询 |
| Spring Boot | 看板后端接口服务 |
| Vue3 + ECharts | 实时可视化大屏展示 |

## 六、为什么使用 Flink CDC

Flink CDC 可以直接读取 MySQL Binlog，不需要业务系统额外埋点或定时抽取。它能够捕获新增、修改、删除等变更事件，适合构建实时业务数据入口。

本项目使用 Flink CDC 采集 `gmall` 数据库，将 Debezium JSON 写入 Kafka `topic_db`。同时配置 `decimal.handling.mode=string`，避免 MySQL Decimal 字段被 Debezium 转成 Base64 字符串，保证金额字段后续可以正常计算。

## 七、为什么使用 Doris

Doris 适合承载实时分析型查询，支持 MySQL 协议访问，查询响应快，适合对接 ADS 指标和可视化看板。

本项目将 DWS 30 秒窗口汇总结果写入 Doris，再基于 Doris 创建 ADS 视图。看板只查询 ADS 视图，不直接读取 Kafka 或 Flink 状态，降低前端复杂度，也保证指标口径统一。

## 八、项目产出

### 数据链路产出

- ODS 业务采集链路：`topic_db -> ods_db`
- ODS 日志采集链路：`topic_log -> ods_log`
- DIM 维度分流链路：`ods_db -> HBase gmall_dim`
- DWD 业务事实分流链路：`ods_db -> dwd_trade_*`
- DWD 日志分流链路：`ods_log -> dwd_traffic_*`
- DWD 订单明细事实宽流：`dwd_trade_order_detail_fact`
- DWS 交易 SKU 窗口汇总：`dws_trade_sku_order_window`
- DWS 省份交易窗口汇总：`dws_trade_province_order_window`
- DWS 流量窗口汇总：`dws_traffic_page_view_window`
- ADS 交易、商品、省份、流量指标视图
- ADS 实时可视化看板

### 看板产出

- 交易总览：GMV、下单次数、下单件数、下单 SKU 数
- 商品排行：SKU GMV Top10
- 地区排行：省份 GMV Top10
- 流量总览：PV、UV、SV
- 趋势图：交易 30 秒趋势、流量 30 秒趋势
- 小时图：小时交易趋势、小时流量趋势

## 十、工单交付标准

- Flink 作业可以正常编译、打包和启动。
- Kafka ODS、DWD 主题可以接收到实时数据。
- HBase `gmall_dim` 命名空间下维表有数据。
- Doris DWS/ADS 表和视图可以查到实时指标。
- 看板可以展示 ADS 指标，并每 5 秒刷新一次。
- 流量和交易造数后，看板对应趋势和指标能够变化。
